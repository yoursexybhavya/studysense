SMART STUDY MONITOR (STUDYSENSE) - COMPLETE ESP32 HARDWARE CONNECTION DETAILS
================================================================================

1. COMPONENT GPIO PINOUT (ESP32 DEVKIT):
--------------------------------------------------------------------------------
- PIR Motion Sensor (OUT)      --> GPIO 27
- HC-SR04 Ultrasonic (TRIG)    --> GPIO 13
- HC-SR04 Ultrasonic (ECHO)    --> GPIO 14 (Via 1k/2k Resistor Voltage Divider)
- Push Button (One Leg)        --> GPIO 22 (Internal INPUT_PULLUP)
- Push Button (Other Leg)      --> GND
- BC547 NPN Transistor (Base)  --> GPIO 23 (Through 1kΩ Resistor)
- Green LED (+)                --> GPIO 26 (Through 220-330Ω Resistor)
- Blue LED (+)                 --> GPIO 25 (Through 220-330Ω Resistor)
- Red LED (+)                  --> GPIO 33 (Through 220-330Ω Resistor)
- All LED (-) Cathodes         --> Common GND

2. POWER & VOLTAGE PROTECTION:
--------------------------------------------------------------------------------
- HC-SR04 VCC                  --> ESP32 VIN (5V from USB)
- HC-SR04 GND                  --> ESP32 GND
- HC-SR04 ECHO VOLTAGE DIVIDER:
    HC-SR04 ECHO pin -> 1kΩ Resistor -> GPIO 14 -> 2kΩ Resistor -> GND
    (Converts 5V ECHO logic pulse down to safe 3.3V for ESP32)
- BC547 NPN TRANSISTOR FOR BUZZER:
    Base      --> 1kΩ Resistor --> GPIO 23
    Collector --> Buzzer Negative (-) Terminal
    Emitter   --> ESP32 GND
    Buzzer (+)--> ESP32 VIN (5V)
